# Caldera Commons

Caldera Commons is an open-source microclimate simulator for Modesto, CA. It evolved from game-server modding into a standalone system for real-world environmental engineering. My mission is to build stable, secure systems that track local thermodynamics, applying professional security principles to support community resilience.

## Core Focus
* **Thermodynamics:** Mapping local environmental data and atmospheric health.
* **Systems Stability:** Prioritizing clean, efficient, and secure architecture.
* **Community Resilience:** Supporting the Modesto area through open-source environmental tools.

## Technical Stack
* Python / Flask
* IoT Data Integration
* Environmental Modeling
